# MicoAir743 USB-only first frame setting (September 29, 2026)

**Scope:** one reversible ArduCopter setting after the untouched USB baseline has been saved. Perform each numbered action separately and report its result before continuing. Keep propellers off and the flight battery, ESC stack cable, Nano receiver and other peripherals disconnected. This card does not release ESC/motor tests, arming, firmware upgrades or flight.

The received board enumerates as `MicoAir743` on `COM8` and Mission Planner reports **ArduCopter V4.5.7**. The untouched [baseline](../evidence/MicoAir743-before-changes-2026-09-29.param) has 1,222 unique well-formed rows. Its `FRAME_CLASS=0` means **Undefined** in [ArduPilot's 4.5.7 parameter list](https://ardupilot.org/copter/docs/parameters-Copter-stable-V4.5.7.html); `1` means **Quad**. Its `FRAME_TYPE=1` already means **X**. [ArduPilot's frame setup](https://ardupilot.org/copter/docs/frame-type-configuration.html) says the class and type should match the physical frame. The project's selected F450 build is a four-motor X layout. The saved original baseline must not be overwritten.

1. **Write only the frame class.** In Mission Planner `CONFIG → Full Parameter Tree`, search `FRAME_CLASS`. Change its value from `0` to `1`. Before writing, use the `Modified` view if available and confirm **only `FRAME_CLASS`** is changed. Click `Write Params`; wait for completion. Do not use `Load from File`, `Reset to Default`, firmware installation, or any other parameter. [Mission Planner parameter-screen guide](https://ardupilot.org/planner/docs/mission-planner-configuration-and-tuning.html). **Report:** whether the write succeeded and what value is displayed. Stop on any error or other modified value.
2. **Reboot and read back.** After Step 1 succeeds, click `DISCONNECT`, unplug the FC USB cable, wait a few seconds, reconnect the same isolated FC and connect to its newly observed COM port at 115200. `FRAME_CLASS` requires a reboot after changing it. Refresh/read parameters and confirm `FRAME_CLASS=1`, `FRAME_TYPE=1`, and `ARMING_CHECK=1`. **Report:** each value and any startup error. Do not assume a write succeeded merely because the pre-reboot screen showed `1`.
3. **Retain evidence.** Save a separate post-change parameter file as `MicoAir743-after-frame-class-2026-09-29.param`; never save over the before-changes baseline. The agent compares exact changed values and records any unexplained difference. If verification fails, leave the battery off and report the failure before any other configuration.

**Pass:** a read-back after reboot shows Quad (`FRAME_CLASS=1`) and X (`FRAME_TYPE=1`) with arming checks still enabled, plus a separate post-change backup. The remainder of controller/receiver/ESC setup needs its own checked instructions and physical wiring gates.
