# B.G.D learning notes

This directory is a durable companion to the B.G.D project for a beginner learning alongside AI agents.

It is not an implementation plan, source of project requirements, agent instruction, or approval record. The authoritative project decisions remain in the issue tracker and its linked research and decision records.

Use these notes to preserve only what helps the owner understand the project:

- `current-context.md` records how the learning chat should work.
- `glossary.md` defines terms after they have been explained.
- `questions.md` keeps a short queue of topics to explain later.

Begin a learning chat by reading `current-context.md`, then the specific issue, plan, diff, part list, or result the owner wants explained. Do not scan the full repository by default. Read broader project context only when the specific artifact depends on it or the owner asks for it.

## Maintenance rule

Keep notes short, dated when facts may change, and written in plain language. Do not copy full agent outputs into this directory. Link to the source artifact and record the explanation or takeaway instead.
