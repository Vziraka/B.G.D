# Phase boundaries

Context continuity and handoff follow `docs/agents/workflow.md`. Use judgment based on task relevance and available context; there is no fixed token threshold, required reset between tickets or ban on mid-task compaction. Preserve consequential decisions, evidence, remaining dependencies and the next action in the current checkpoint when possible. Create separate user tasks only when requested. Use subagents for useful bounded work; the main agent retains integration and continuation responsibility.
