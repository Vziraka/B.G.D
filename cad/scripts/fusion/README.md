# Fusion-hosted scripts

Repository-managed Fusion Python entry points execute through the authorized official MCP; no copy/install into Fusion's add-in directory is required. The `adsk` API runs inside Fusion, not ordinary shell Python.

Execution history: commission units → import source → inspect profiles → build first frame hypothesis → screen adapter → inspect omitted layers → revise stack → inspect intermediate collisions → finalize/capture/export reference. The manifest pins these scripts. They are one-time guarded operations, not an idempotent whole-aircraft generator; inspect partial execution instead of blindly rerunning. Preserve historical reports and use the final snapshot manifest for actual positions/interference results.
